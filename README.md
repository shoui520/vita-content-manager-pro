<h1 align="center">Content Manager Pro</h1>

<p align="center"><strong>Transfer and copy music, videos and photos to and from your Vita with ease. No drivers, no CMA/QCMA.</strong></p>

## 🛠️ Usage

[Download here](https://github.com/shoui520/vita-content-manager-pro/releases)  

Install the .vpk onto your Vita, and use the desktop companion app to transfer files. Content Manager Pro uses WiFi by default; ensure the correct IP address is inputted in the desktop app to connect.  

Content Manager Pro can automatically convert files to ensure that they're usable on the Vita, to do this you need `ffmpeg` installed and available on your PATH.  
To use USB transfer mode, you need to put `vcm_mtp_bridge.suprx` in your taiHEN config under `*main*. It is not needed if you are using WiFi transfer.

## ✨ Features
- Imports media directly into the Vita’s official Photos, Music, and Videos libraries—without Sony Content Manager Assistant or PSN linking.
- Automatic Vita-compatible conversion for images, audio, video, animated GIFs, and otherwise unsupported formats.
- Supports Videos app folders, including importing a PC folder as a named Vita video folder.
- Native Vita subtitle support through `.m4t` generation from SRT and ASS sources.
- Eligibility checks clearly show whether media can be imported as-is or needs conversion.
- Native feeling libpaf Vita sysapp that can run without closing the currently suspended application.
- Windows desktop application styled after Sony’s Content Manager and Vita/PlayStation interface design.

And many more under the hood!
